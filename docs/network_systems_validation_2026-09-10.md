# Interacting-system validation — 10 September 2026

Scope: Stage A host, Stage B networks and Stage C cross sections. No full
multi-system cave mesh, rock population or engine import was generated by this
validation. The trial uses the Earth profile; it is not a multi-body realism
benchmark.

## Regression coverage

140 targeted tests and 26 subtests passed across the network, config, section,
world-contract, mesh-continuity and tiled-geometry suites, including 30 new
interaction tests. The new cases cover supply conservation, capacity-weighted
splitting, thermal mixing, transported source identities, one-copy shared
geometry, deterministic planning, short release spikes, malformed membership,
invalid controls, insufficient host space, host-cost sensitivity and the
single-system dispatch path. Ruff passed for all affected Python files.

The combined regression run passed 133 tests before seven additional thermal
and malformed-metadata cases were added; the final fast run passed all 80 cases
in the systems, acceptance and config suites. Together these cover the stated
140 distinct tests. Logs: `tmp/system_regression_tests.log` and
`tmp/system_unit_final.log`.

sources, five merges, four splits, two outlets and 16 segments. Approximately
1,813 m of passage is shared. All 32 network/section checks passed; no section
was marked unstable by the existing roof screen. The first candidate was
accepted without repairs. No claim of geological certification follows from
these checks.
