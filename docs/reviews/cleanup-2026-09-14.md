# Cleanup after the mobility and texture repair campaign

Date: 14 September 2026. The validated implementation before this cleanup is
preserved in commit `c5d8922`. Generated assets and the historical campaign
records remain separate from the maintained implementation.

## Changes

The cleanup removes three superseded command-line scripts, totalling 572 lines:

| Removed script | Reason and replacement |
|---|---|
| `scripts/generate_inspection_case.py` | A separate stage orchestration path that could drift from the automatic inspection and repair pipeline. Use `plume-generate` or `plume-check` with a recorded configuration. |
| `scripts/complete_inspection_case.py` | Continued that alternate path from local intermediate checkpoints, rather than using the current recovery and export contracts. Use the full pipeline. |
| `scripts/package_inspection_exports.py` | Copied visual assets without the current dedicated collider and continuous material bundle contract. Use the maintained pipeline exporters. |

The floor/roof intersection calculation now lives in `stages/triangle_queries.py`.
Mesh inspection, route clearance and resolution comparison share it directly;
route clearance no longer imports it back from mesh inspection. The shared
route resampler has a descriptive public name. Neither calculation's executable
body changed: an AST comparison against `c5d8922` verified both, ignoring only
the added documentation and renamed function declarations.

Two new regression tests cover empty clearance queries and stacked cavities,
including probes on the boundary and in solid space between cavities. The
existing route, collider, resolution and repair tests exercise the callers.

The README now leads with the complete automatic workflow and explicitly
identifies the geometry-only research helper's narrower scope. The reliability
guide uses the maintained campaign command. CI checks the whole repository
with Ruff and verifies the installed wheel's default configuration and all eight
Blender/Unity/Unreal material support files, independently of the source tree.

## Deliberately retained capabilities

Call-site and syntax-tree review found no additional private functions without
consumers in the maintained package, tests and scripts. Static reachability is
supporting evidence, not proof that every possible execution path is exercised.

The geometry-only research helper remains in use by body, resolution and
surface-relief studies. Rendering existing scenes, revising an existing neutral
asset's material and independently checking an exported asset also remain useful
operations. They are not replacements for the full generation acceptance gate.

Optional emplacement history, external scientific-data adapters and historical
measurement records remain supported. An optional path does not become obsolete
because a rock-free Earth campaign does not exercise it. Historical source already
removed in previous cleanups is recoverable from the recorded Git checkpoints;
no compatibility copies were reintroduced.

## Verification

The cleanup changes the package source fingerprint. The six-case V3 campaign
continues to describe `c5d8922`; it is not claimed as a fresh run of this revision.
Validation of the cleanup itself is recorded separately in
[`cleanup-verification-2026-09-14.json`](cleanup-verification-2026-09-14.json).

The installed wheel was checked from a separate temporary installation, with
the source checkout excluded as its import origin. It contains the default
rock-free configuration, the 0.5 m route requirements and all eight material
support files. The compressed wheel is 453,260 bytes; it does not package
generated caves or the campaign image archive. The source distribution also
built successfully.

The full suite passed **901 tests and 59 subtests**, with 20 optional checks
skipped, in 769.75 seconds on Python 3.13.5. The overlapping focused suite passed
135 tests. Ruff passed across the repository; mypy passed across 110 source files;
compilation, installed-dependency compatibility and offline lock consistency also
passed. The [full test log](cleanup-tests-2026-09-14.txt) is preserved with its hash.

The local run did not execute the CI Python 3.12 job or re-run optional native
checks skipped by the general suite. These limits are recorded in the verification file.
No new native-editor or long-network generation campaign is claimed by this
cleanup. Broader completion criteria are in the subsequent
[gap assessment](remaining-gaps-2026-09-14.md).
